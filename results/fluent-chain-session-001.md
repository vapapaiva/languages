## Errors This Session

### 🔴 Recurring — High Priority

**Personal *a* (×4)**
- *conocer la gente* → *conocer **a** la gente*
- *conocer más gente* → *conocer **a** más gente*
- Rule: any human direct object requires *a* before it, no exceptions

**Sociedad vs socio (×2)**
- *integrarme en la socio* → *integrarme en la **sociedad***
- *socio* = партнёр/член; *sociedad* = общество

### 🟡 Moderate

| Error | Correction | Pattern |
|---|---|---|
| *cuando vienas* | *cuando **vengas*** | Subjuntivo irregular: venir → vengo → vengas |
| *tendrá que encontrar* (yo) | ***tendré** que encontrar* | Future tense person agreement |
| *la corrida* (running) | *el running / salir a correr* | La corrida = bullfighting! |

### 🟢 Minor

| Error | Correction |
|---|---|
| *mucha calor* | *mucho calor* (calor = masculine) |
| *en lugar de el* | *en lugar **del*** (de + el = del) |
| *suelen estar cerrado* | *cerrados* (plural agreement) |
| *preguntarle esas preguntas* | *hacerle esas preguntas* |
| *cerca de mercado* | *cerca **del** mercado* |
